AstrBot Backup
Personal project · 个人项目
Encrypted backups · Google Drive

A quiet, personal backup workflow.

AstrBot Backup is a personal-use utility designed to place encrypted backup archives in the owner’s Google Drive. It is not offered as a public service and is not intended for other users.

Personal use only

Operated by its owner for the owner’s own AstrBot backup workflow.

Google Drive destination

Google authorization is used only for the Drive backup workflow.

Encrypted archives

Backups are intended to be encrypted before storage. Encryption configuration and key management belong to the backup setup; this page does not claim an independent audit.
