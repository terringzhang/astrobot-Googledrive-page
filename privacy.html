Privacy Policy

Effective date: October 25, 2026

This policy describes the personal AstrBot Backup Google OAuth application operated by the owner of the GitHub account terringzhang. The application is for the owner’s personal use only. It is not a multi-user service and is not intended to collect information from the public.

What the application does

The application supports the owner’s AstrBot backup workflow by using Google authorization for Google Drive backup operations. Backup archives are intended to be encrypted by the backup workflow before being stored in Drive. This page does not represent that the application independently encrypts files, verifies encryption, or has undergone a security audit. The owner is responsible for configuring encryption and safeguarding any encryption keys.

Information and processing

  • Google OAuth authorization information is used to authorize the requested Google Drive backup operation.
  • The backup workflow may create or update backup archive files in the owner’s Google Drive. Google may process authentication data, file data, and related technical information under Google’s own terms and privacy policy.
  • The application is not intended to sell personal information, use Drive content for advertising, or disclose it to other people. No analytics or advertising use is described by this policy.

Processing and storage details depend on the software configuration and hosting environment used by the owner. This site does not claim that OAuth tokens are stored in a particular way, that logs are retained for a particular period, or that any specific security controls have been implemented.

Retention and deletion

Backup files stored in Google Drive remain there until the owner deletes them. Revoking Google access does not itself delete existing Drive backups. The owner can review and delete those files directly in Google Drive.

Revoke access

The owner can remove the application’s Google account access from Google Account third-party connections. Revocation prevents future authorized access, subject to Google’s processing of the revocation. Existing backup files must be deleted separately from Drive if desired.

Changes and contact

This policy may be updated when the personal application or its data handling changes. For questions about this personal project, contact the owner through their GitHub profile.

隐私政策

生效日期：2026年10月25日

本政策适用于由 GitHub 账号 terringzhang 的所有者运营的个人 AstrBot Backup Google OAuth 应用。该应用仅供所有者个人使用，不是面向多名用户的服务，也不用于收集公众信息。

应用用途

该应用通过 Google 授权支持所有者的 AstrBot 备份流程，并用于 Google Drive 备份操作。备份流程旨在将加密后的备份归档文件存入 Drive。本页面不表示应用本身一定会独立加密文件、验证加密结果或已经通过安全审计。所有者负责配置备份加密并妥善保管加密密钥。

信息及处理方式

  • Google OAuth 授权信息用于授权所请求的 Google Drive 备份操作。
  • 备份流程可能在所有者的 Google Drive 中创建或更新备份归档文件。Google 可能依据其自身条款和隐私政策处理认证数据、文件数据及相关技术信息。
  • 本应用不以出售个人信息、将 Drive 内容用于广告或向他人披露为目的。本政策未描述任何分析或广告用途。

实际处理和存储细节取决于所有者使用的软件配置及运行环境。本页面不声称 OAuth 令牌以某种特定方式存储、日志保留某个固定期限，或已实施任何特定安全控制。

保留与删除

存储在 Google Drive 中的备份会保留至所有者将其删除为止。撤销 Google 授权本身不会删除 Drive 中已有的备份。所有者可直接在 Google Drive 中查看并删除这些文件。

撤销授权

所有者可通过 Google 账号的第三方连接管理页面移除此应用的访问权限。撤销后，应用将无法继续进行未来的授权访问，具体撤销处理以 Google 为准。若希望删除已有备份，还需在 Drive 中单独删除。

政策变更与联系

如果个人应用或数据处理方式发生变化，本政策可能随之更新。如对本个人项目有疑问，可通过所有者的 GitHub 个人主页联系。
